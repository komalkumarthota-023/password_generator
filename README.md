# Password Generator using Python

This is a simple password generator project made using Python.  
The program creates strong and random passwords based on the length entered by the user.

I created this project as a beginner-level Python project for practice and learning purposes. It is easy to understand and useful for learning concepts like loops, strings, random functions, and user input in Python.

## Features

- Generates random passwords
- User can choose password length
- Uses:
  - uppercase letters
  - lowercase letters
  - numbers
  - special symbols
- Simple and beginner friendly

## Technologies Used

- Python 3
